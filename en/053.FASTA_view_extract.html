Step 3: Matching Parameters
Exact match: Each item in the ID list must exactly equal the full sequence header in the FASTA (without >), including the description.
Prefix match: Each item in the ID list is the start of a FASTA sequence header. For example, if the FASTA header is "atp6 len=xxx", providing "atp6" will match.
Fuzzy match: As long as the FASTA sequence header contains any field from the ID list, it matches. For example, if the FASTA header is "abcd", providing "bc" will also match.
Characters per line: Each sequence is wrapped at this width when displayed and exported. 0 means no wrapping.
