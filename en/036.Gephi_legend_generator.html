Note: The table can be exported from Gephi Data Laboratory. You can add custom columns for node labels.

Note: Adjust the scale factor to resize the entire legend. Set the title to "Phylum" or "Modules" as needed. The classification column should match the attribute used for coloring in Gephi (e.g., att2 for Phylum, att4 for Modules as shown in video tutorial).
