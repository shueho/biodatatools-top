RSCU Calculator (Relative Synonymous Codon Usage)

Relative Synonymous Codon Usage (RSCU) calculation.

Step 1: Import FASTA sequences
Instructions: Paste the CDS sequences of protein-coding genes (can be extracted using the GenBank Feature Extractor tool), then select the correct codon table. No warning will be given for incorrect codon table selection.
Note: For better data presentation, the content before the first space in sequence ID will be used as gene name. Please rename duplicates in advance!
You can either merge all sequences for RSCU calculation or calculate each sequence individually.
Step 2: Parameter settings

Format: codon amino_acid, use TER for stop codons, one correspondence per line
