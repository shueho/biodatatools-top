Transition / Transversion Calculation

Calculate pairwise transition counts, transversion counts, total differences, and R ratio from aligned sequences, with support for count/frequency output.

Step 2: Calculation parameters
Notes: Transitions: A↔G, C↔T; Transversions: A↔C, A↔T, G↔C, G↔T.
R = transitions / transversions. If transversions = 0 and transitions > 0, displays +Inf; if both are 0, displays Nan.
Frequency mode: the denominator can be either the full alignment length (including gaps) or the number of valid sites (excluding gaps). In complete deletion mode, all sequence pairs use the same denominator; in pairwise deletion mode, each pair uses its own number of valid sites.
R is a ratio and is not affected by count/frequency mode.
