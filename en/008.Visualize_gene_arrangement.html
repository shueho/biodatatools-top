Gene Arrangement Visualization (Gene Rearrangement Map)

Visualize gene order and rearrangements with support for distinguishing positive/negative strands and non-coding regions.

Step 1: Import Gene Arrangement File

Format Instructions

• Lines starting with "#" are treated as comments/headers and will be displayed as section titles (e.g., taxonomic group names).
• For data rows: first column = species name (Latin name), remaining columns = gene names, separated by TAB (Excel copy‑paste format).
• Prefix a gene name with "-" to indicate it is encoded on the negative strand.
• Prefix with ":" to mark the gene as missing (displayed as an empty rectangle with dashed border).
• Prefix with "!" to mark the region as non‑coding (displayed as a blue line with gene name).
• Multiple symbols can be combined (e.g., ":-gene").
• If no genes are marked as negative strand, a linear arrangement will be drawn.
• If spacing or canvas size is not ideal, you can fine‑tune the SVG in Adobe Illustrator.
• Click "Load Example" to see the expected input format.
