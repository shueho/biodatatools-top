Step 2: Parameters
Method: selected features (e.g. CDS) are used as anchors and traced upward through Parent to the top-level feature (default gene). Multiple anchors that map to the same top-level feature are de-duplicated by ID and counted only once.
Top-level feature: typically gene; can also be used to count transcript density.
Window interval: half-open (start, end]; e.g. (100000, 200000] covers positions 100001–200000.
Positioning rules:
  · By midpoint: pos = floor((start + end) / 2), same for plus and minus strands;
  · Mean anchor midpoint: take the midpoint of every selected anchor belonging to the gene and use their average as the gene position;
  · By start: start on plus strand, end on minus strand;
  · By end: end on plus strand, start on minus strand;
  · Fully inside window: both start and end must fall inside the window; partial genes will not be counted.
Chromosome length: if a chromosome feature is specified, its maximum end is used; otherwise the maximum end over all features on that chromosome is used.
