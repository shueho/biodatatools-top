Table Column Explode

Split separated values in a column into multiple rows, keeping other columns. Supports any separator (semicolon, comma, space, slash, etc.).

Step 1: Import Table Data
Note: First row should be column names. Supports tab, comma, or space delimiters.
Step 2: Explode Settings
Description: Split each value in the selected column into separate rows, keeping other columns unchanged. If "Trim Whitespace" is checked, spaces around each item will be removed.
