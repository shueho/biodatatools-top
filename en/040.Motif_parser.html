Motif (MEME/MAST) Result Parser

Parse MEME/MAST output files and export information tables for drawing domain/motif diagrams or phylogenetic trees in the BioStatPlot module of this toolkit.

Step 1: Import result file
Where to get the file:
① Online: go to MEME Suite, run MEME (or MAST), and download "MEME text output" or "MEME XML output" from the result page (for MAST: "MAST text output" / "MAST XML output").
② Local: run meme or mast from the command line, then use meme.txt / meme.xml (or mast.txt / mast.xml) from the output directory.
Upload or paste any of the above files. All four formats (MEME/MAST, txt/xml) are supported. The exported table can be used for the domain/motif track in the phylogenetic tree plotter.

After parsing, motif IDs, consensus sequences and related information will be shown here.
