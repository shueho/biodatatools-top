Motif (MEME/MAST) Result Parser

Parse MEME/MAST output files and export information tables for drawing domain/motif diagrams or phylogenetic trees in the BioStatPlot module.

Step 1: Import Result File
File sources:
① Online: visit MEME Suite to run MEME (or MAST), then download “MEME XML output” (for MAST: “MAST XML output”) from the result page.
② Local: run meme or mast from the command line and use meme.xml (or mast.xml) from the output directory.
Upload or paste either file above. The exported results can be used to draw the domain/motif track in a phylogenetic tree.
Step 2: Motif Sequence and Base/Amino Acid Proportions

After parsing, the sequence and per-position base/amino acid proportions of each motif will be displayed here.

Note: Can be used to draw sequence logo plots; Sites indicates the number of occurrences of the current motif.
Step 3: Select Output Style and Export

After parsing, the preview table will be displayed according to the selected output style.
