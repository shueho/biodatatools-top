Phylogenetic Tree Tip Label Renaming

Import a Newick/NEXUS tree file, batch-rename leaf labels (tips), and export in the selected format.

Step 1: Import Tree File
Instructions: Newick and NEXUS are supported; for NEXUS, the first tree is read and names from the translate block are applied automatically. Labels may be wrapped in single quotes (e.g., 'Danio rerio'); support values, branch lengths, and metadata are preserved.
Step 2: Edit Label Mapping Table
Label Mapping Table 0 rows
Instructions: The first column is the old label, the second column is the new label, separated by a tab; leave the new label blank to keep it unchanged. After importing, a single-column list is generated automatically. You can copy it to Excel/a text editor, fill in the second column, then paste the whole thing back here and click "Apply Changes".
