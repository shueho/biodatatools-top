SVG Format Converter

Convert SVG vector graphics to PNG, JPG, WEBP, PDF, EPS and other formats with custom size and resolution.

Step 1: Import SVG File
Note: External resources referenced by the SVG (images, fonts, external styles) may not load in the browser. Inline external resources or convert them to base64 before importing. If your SVG was exported by the BioStatPlot module of this toolkit, it usually has no external dependencies and can be used directly.
Step 2: Export Settings
Note:
PNG/WEBP: Supports transparent background, suitable for web and further layout.
JPG: Does not support transparent background; transparent areas will be filled with the background color.
PDF / EPS: Uses bitmap embedding; rendering resolution is determined by pixel size and DPI. For vector PDF/EPS, use professional software such as Illustrator.
Size: In scale mode, export pixels = original size × scale factor. In target width mode, height is calculated automatically from the original aspect ratio.
