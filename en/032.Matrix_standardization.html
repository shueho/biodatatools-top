Matrix Standardization Tool

Import a matrix, perform row/column standardization, and calculate relative values.

Step 1: Import Matrix Data
Note: First row is column names, first column is row names. Supports tab, comma, or space delimiters.
Step 2: Standardization Parameters
Formula Reference:
Min-max: X = (x - min) / (max - min)   (scales to [0, 1])
Z-score: X = (x - μ) / σ (sample SD)   (mean=0, variance=1)
Mean: X = (x - mean) / (max - min)   (scales to [-1, 1])
Pareto: X = (x - mean) / sqrt(σ) (sample SD)
Center: X = x - mean
Relative Abundance: X = x / column or row sum
Note: Please select the appropriate direction (row/column) according to your analysis needs.
