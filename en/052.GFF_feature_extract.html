GFF Feature Sequence Extractor

Extract feature sequences from a genome FASTA based on GFF annotations, supporting multi-segment concatenation, reverse complement for negative strand, and upstream/downstream extension.

Step 1: Import Genome FASTA File
Note: Supports GB-scale genome files. The FASTA sequence name is taken from the first word after >, and must match the chromosome name in the first column of the GFF.

Step 3: Extraction Parameters

Please import a GFF file first
Hint: Based on the GFF preview, choose an attribute field that is globally unique within the selected feature type as the sequence ID (e.g., ID, Name, gene_id). If the same ID corresponds to multiple rows (e.g., CDS spanning introns), the program will concatenate them in coordinate order. For the negative strand, it concatenates in the forward genomic orientation first, then reverse-complements the whole sequence. Rows missing this attribute will be skipped.
Note: Upstream/downstream are relative to the transcription direction. For the positive strand, upstream lies before the start coordinate and downstream lies after the end coordinate; for the negative strand, upstream lies after the end coordinate and downstream lies before the start coordinate. Upstream/downstream are concatenated in transcription direction, then the whole sequence is reverse-complemented if on the negative strand.
Preview: The result area in Step 4 displays the first N sequences. For the rest, please use copy or download. If the output file is too large, you can use the Large File Viewer to view it.
