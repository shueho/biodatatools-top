Table Merge Tool

Supports left merge, right merge, inner merge, outer merge, and horizontal stack.

Step 1: Import Left Table
Note: First row should be column names. Supports tab, comma, or space delimiters.
Step 2: Import Right Table
Note: First row should be column names. Supports tab, comma, or space delimiters.
Step 3: Merge Settings
Merge Mode Description:
Left Merge: Keep all rows from left table, append matched columns from right table, fill missing with NA.
Right Merge: Keep all rows from right table, append matched columns from left table, fill missing with NA.
Horizontal Stack: Concatenate columns row-wise without matching keys.
Inner Merge: Keep only rows with matching keys in both tables (intersection).
Outer Merge: Keep all unique keys from both tables, fill missing with NA (union).
Column Output: All left table columns keep original names. All right table columns are included; if a right column name duplicates a left column name, a _R suffix is added.
Step 4: Merge Result
Import both tables and click "Execute Merge"
