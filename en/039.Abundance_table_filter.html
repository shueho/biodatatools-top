Step 2: Parameter Settings

Four Modes Description

Mode 1 (IN filter): Keep ASV/OTU/species/genes where the proportion of samples with relative abundance > relative abundance threshold is ≥ prevalence threshold.
Mode 2 (ADD filter): Keep ASV/OTU/species/genes with prevalence ≥ prevalence threshold AND mean relative abundance > relative abundance threshold.
Mode 3 (OR filter): Keep ASV/OTU/species/genes with prevalence ≥ prevalence threshold OR mean relative abundance > relative abundance threshold.
Mode 4 (Zero out low abundance): No row filtering; relative abundance values below threshold are set to 0.
