距离计算方法： 采用 Haversine 公式 计算球面大圆距离，假设地球为完美球体（平均半径R = 6371.0088km）。
计算公式（lat和lon为弧度制数值）：
a = sin²(Δlat/2) + cos(lat1)*cos(lat2)*sin²(Δlon/2)
d = 2 * R * arcsin(√a)
如果你在研究中用到本工具，你可以写：
地理距离矩阵通过Haversine公式计算得到。
The geographic distance matrix was calculated using the Haversine equation.
注意事项： Haversine公式适用于大多数地理分析场景（如种群遗传学、生态学中的距离隔离分析）。对于需要 高精度要求 的专业测量（如工程测绘、精密导航），建议改用考虑地球椭球体形状的 Vincenty 公式 或使用专业GIS软件（如 QGIS、ArcGIS等）计算。
