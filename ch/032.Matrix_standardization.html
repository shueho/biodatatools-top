矩阵标准化工具

导入矩阵数据，按行/列进行标准化及相对值的计算。

第一步：导入矩阵表格
说明： 第一行为列名，第一列为行名。支持制表符、逗号或空格分隔。
第二步：设置标准化参数
公式说明：
Min-max标准化： X = (x - min) / (max - min) 把数据压缩到[0, 1]之间。
Z-score标准化： X = (x - μ) / σ （σ为样本标准差） 让数据均值为0，方差为1。
Mean标准化： X = (x - mean) / (max - min) 把压缩到[-1, 1]之间。
Pareto标准化： X = (x - mean) / sqrt(σ) （σ为样本标准差）
Center中心化： X = x - mean
相对丰度/表达量计算： X = x / 列或行的总和 用于相对丰度/表达量的计算
注意：请按照需求正确选择按列或按行进行标准化！
