Phylogenetic Tree Visualization

Read phylogenetic tree files in Newick / NEXUS / PhyloXML format and visualize them.

Step 1: Import Phylogenetic Tree
Import Node Metadata
The unique identifier of a node is ID. If the header of the first column is ID (case-insensitive), matching is performed by ID. Otherwise, matching uses Label/UID (duplicates may exist; only the first match will be taken). Remaining columns are merged as meta fields. Labels, branch lengths, support values and other non-meta data will NOT be modified. If you are unsure about the ID corresponding to a node, you can view the details in the collapsible node data table below.
