Once checked, other settings in this step will be locked and the imported matrix will be used directly as the result.
Format: the first row and the first column are variable names; the lower-left triangle holds correlation coefficients; the upper-right triangle holds significance p-values; the diagonal should be 1.
If the matrix is placed incorrectly, the result will be wrong.
If p-values are not available (e.g. the upper-right triangle is empty), the heatmap can still be drawn, but no significance information (stars / p-values / significance color blocks) will be shown.
