Categorized Bar Chart

Sub-categories nested within big categories, with each big category colored differently. Supports vertical / horizontal orientation, range bars and error-value bars.

Step 2: Select Data Columns and Sorting
Data Columns
Each big category may contain several sub-categories, and different big categories can have different sub-categories. Colors are assigned per big category.
Sorting and Group Order
Checked: big categories in order, sub-categories inside sorted by the rule; Unchecked: all sub-categories sorted together (colors interleaved).
Leave empty to use input order; unlisted items are appended.
