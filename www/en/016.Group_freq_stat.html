Group Statistics for Base/Amino Acid Usage

Import FASTA sequences, set groups, then calculate the frequency or count of bases or amino acids by group.

Step 1: Import FASTA Sequences
Step 2: Set Groups
Sequence Name → Group Name Mapping Table 0 entries (Copy to Excel, modify the second column, then paste back and click "Apply Groups")
Step 3: Statistics Parameters and Results
Complete grouping and click "Run Statistics" to view results.
